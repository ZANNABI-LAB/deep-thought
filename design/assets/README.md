# 브랜드 에셋

## 확정 자산

| 파일 | 용도 | 비고 |
|---|---|---|
| `station-hero.png` | 메인 배경 | 4색 · 1672×941 · 134 KB |
| `mark2.svg` | **소형 마크 후보** | 64격자 · 177 rect · 32px에서도 읽힘 |
| `logo.svg` | 대형 로고 | 전신 · 2,017 rect · 26px에서는 무너진다 |
| `logo-head.svg` | 중간 크기 대안 | 얼굴 크롭 · 34px 이상 |
| `favicon.svg` | 헬멧 마크 | 16px에서 가장 안정적 |

현재 사이트에는 **배경만** 적용되어 있다. 마크·파비콘은 재제작 예정.

## 팔레트

```
#05080A  배경      #DCE7DF  전경
#3DFF88  악센트    #6F7D74  중간 회색(배경 하프톤 전용)
```

마크·로고는 3색, 배경만 4색이다. 배경을 3색으로 줄이면 회색 하프톤이 갈 곳을
잃고 그린으로 흡수되어 좌우 장비가 초록빛이 된다.

## 원본

생성 이미지 원본(`*-src.png`)은 용량이 커서 저장소에 넣지 않는다(`.gitignore`).
다시 만들 일이 있으면 원본을 구해 아래 순서로 처리한다.

```bash
npm run pixelize -- <원본.png> <정리본.png> --grid <격자수>
npm run dot2svg  -- <정리본.png> <결과.svg> --bg "#05080a"
```

`pixelize`는 채도로 먼저 갈라 양자화한다. 단순 RGB 거리를 쓰면 중간 회색이
형광 그린에 더 가깝게 계산되어 선 경계가 초록으로 번진다.

## 마크를 다시 만들 때

**작게 쓸 마크는 작게 설계해야 한다.** 1px 선으로 그린 도안은 32px에서
선이 뭉개져 회색 덩어리가 된다. 면으로 채운 64격자 도안(`mark2.svg`)은
32px에서도 실루엣과 안경이 살아남았다. 마크와 대형 로고는 별도 도안이다.
