인증과 인가: 웹 보안의 핵심 개념과 구현
인증(Authentication)은 “누구인가”를 확인하는 절차이고, 인가(Authorization)는 그 주체가 “무엇을 할 수 있는가”를 결정하는 절차입니다. 둘은 자주 뒤섞여 쓰이지만 책임이 다릅니다.
// 인가 실패는 401이 아니라 403이다
if (!user.can('order:cancel')) {
  throw new Forbidden()
}
