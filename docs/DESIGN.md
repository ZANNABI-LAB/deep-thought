## 0. 작업 원칙

- **콘셉트는 방향이지 완성본이 아니다.** 콘셉트 그림과 시안 D(`proto/home-directions` 브랜치의 커밋 `2311481`, `apps/web/app/proto/d`)는 구도·화풍·동작의 견본이다. 컴포넌트를 만들 때마다 이 콘셉트를 바탕으로 디테일과 분위기를 **다시 설계해서** 구현한다. 시안 코드를 그대로 옮기지 않는다.
- 컴포넌트 하나를 만들 때마다 콘셉트 그림과 나란히 비교해 보고 결정한다.
- 콘셉트 그림은 아트 디렉션 기준이며 그대로 리소스로 쓰지 않는다.

## 2. 비전

**Deep Thought는 읽고, 탐험하고, 질문하고, 놀 수 있는 개인 지식 우주다.**

- **사이트 이름:** Deep Thought (『은하수를 여행하는 히치하이커를 위한 안내서』의 컴퓨터)
- **세계관:** *Zannabi's Little Universe*
- **마스코트:** **Zannabi(잔나비)**, 우주를 탐험하는 원숭이 ("잔나비"는 원숭이의 옛 우리말)
- **부브랜드:** Zannabi Lab
- **주제:** 소프트웨어 엔지니어링, AI/에이전트, 사이드 프로젝트, 독서·철학, 사고와 실험의 기록

### 핵심 원칙

1. 게임처럼 재미있지만 **블로그로서도 훌륭해야 한다.**
2. HUD 조작은 **보조 탐색 경로**다. 메뉴·검색·직접 URL로 모든 콘텐츠에 갈 수 있어야 한다.
3. 귀여운 마스코트와 전문적인 콘텐츠를 분리해 표현한다.
4. 첫인상보다 **읽기·접근성·성능·모바일**을 우선한다.
5. **사용자는 기다리지 않는다.** 화면은 즉시 보이고, 움직임은 준비되는 대로 더해진다.

## 3. 홈 콘셉트: 우주선 창

**작은 픽셀 아트 우주선의 큰 창 너머로 진짜 우주를 바라보며, 창에 비친 게임보이 HUD로 사이트를 조종한다.**

### 3.1 층

| 층 | 내용 | 화풍 | 만드는 법 |
| --- | --- | --- | --- |
| 창밖 | 행성 2개, 바위, 성운, 별 | **실사** | 4K 그림을 시작 프레임으로 Kling 3.0 Omni (Frames) 10초 → 4K 업스케일(Bytedance) → 정방향+역방향 이어 붙인 핑퐁 반복(`public/world/space-loop-4k.mp4`, 8.3MB, 데스크톱만). 포스터는 영상 첫 프레임 |
| 우주선 | 모서리를 깎은 큰 창틀, 창턱 바닥, 깜빡이는 표시등 6곳 | **픽셀 아트** (던전앤파이터 정도 밀도) | GPT 그림 → `window_frame.py`(2px 격자, 48색, 가짜 글자 제거, 불빛 분리) → `WindowFrame.tsx`가 정수배로 그리고 이음 열·행을 복제해 화면 비율에 맞춘다 |
| Zannabi | 왼쪽 아래 바닥에 서서 창에 두 손을 대고 우주를 올려다본다. 비스듬한 뒷모습, 유리 헬멧 | **픽셀 아트** (창틀과 같은 2px 격자) | 스프라이트 (GPT 그림 → 격자 정리) |
| HUD | 창 유리에 비친 화면. 왼쪽 문구, 오른쪽 조작 패널, 조준선, 메뉴 | **게임보이 4색 도트** | 웹 코드 |

### 3.2 배치

```text
┌──────────────────────────── 픽셀 아트 창틀 ────────────────────────────┐
│ Deep Thought                       Writing Projects Reading Arcade │
│                                        [+] TARGET: WRITING · 4.2 AU│
│ ┌ > ZANNABI LAB // EST. 2026 ┐            ┌ MENU  ASK  ARCADE ─┐   │
│   (제목 문구)                              │                    │   │
│   (한 줄 소개)                             │  조작 패널 (세로)  │   │
│ └                            ┘            │                    │   │
│   [Zannabi: 바닥에 서서 창을 바라봄]       └────────────────────┘   │
└──────────────────────────────── 바닥 ───────────────────────────────┘
```

- 왼쪽 문구 HUD와 오른쪽 패널 HUD가 좌우 균형을 이룬다.
- 우주가 주인공이다. 창틀은 가장자리만 감싸고, HUD는 얇게 그린다. 복잡한 SF 장식을 넣지 않는다.

### 3.3 HUD

- **색:** 게임보이 4색 `#0F380F` · `#306230` · `#8BAC0F` · `#9BBC0F`. 큰 제목만 크림색(`#F1ECE2`) 세리프로 둬서 읽기 쉽게 한다
- **글꼴:** 도트 글꼴 Galmuri (영문·한글). 설계 크기의 정수배만 쓴다 (Galmuri11·9·7의 2배)
- **메뉴:** Writing · Projects · Reading · Arcade (Explore 없음)
- **조준선:** 메뉴를 고르면 창밖의 다른 천체로 옮겨 가며 `TARGET: <메뉴> · <거리>`를 띄운다
- **오른쪽 패널 탭**
  - **MENU:** 목적지 고르기 → 페이지로 이동
  - **ASK:** Zannabi와 대화 (범위 미정, §7)
  - **ARCADE:** 패널 안에서 미니게임을 바로 한다 (§6)
- **조작:** ↑↓ 선택, ←→ 탭, A = Enter/Z, B = Esc/X, 클릭도 모두 된다

### 3.4 움직임

- **움직이는 것은 사물만:** 창밖 우주(바위 회전·떠다님, 성운 일렁임, 큰 별 반짝임, 행성 대기 빛), HUD, 불빛, Zannabi의 작은 동작. **카메라와 행성 위치는 고정**
- 별똥별과 마우스 시차는 영상이 아니라 웹 코드로 얹는다 (영상에 넣으면 같은 자리에서 반복돼 티가 난다)
- 별똥별(`components/space/ShootingStars.tsx`): 7~19초에 한 번, 두 행성이 마주 보는 축(약 40.5°)을 따라 위 행성 쪽에서 아래 행성 쪽으로, 축 양옆 빈 통로에서만 떨어진다. 행성·바위 앞은 지나가지 않는다. 개발 서버에서 `?meteors`면 자주 나온다
- `prefers-reduced-motion`이면 영상 대신 정지 그림, HUD 애니메이션 끔

### 3.5 모바일 (예정)

창틀 없이 우주와 HUD를 세로로 쌓는다. 영상 대신 정지 그림.

## 7. 콘텐츠 · SEO · 운영

### 7.1 콘텐츠

- 원본: `apps/web/content/{writing,projects,reading}/*.mdx`, 빌드 시 정적 생성. 지금은 `writing`만 있다.
- 프런트매터 스키마는 빌드 시 검증한다 (`lib/writing.ts`).
- 새 글은 `content/writing/_template.mdx`를 복사해 영문 소문자·하이픈 이름으로 저장한다. `draft: true`면 개발 서버에서만 보인다.
- 시설 콘텐츠 순서: Writing → Projects → Reading → Ask → Arcade. 오픈에는 Writing·Projects가 필수.

### 7.2 URL

| 경로 | 내용 |
| --- | --- |
| `/` | 홈 (만드는 중. 지금은 창밖 우주 배경만) |
| `/writing`, `/writing/[slug]` | 글 목록, 글 상세 (구현됨) |
| `/projects`, `/reading`, `/about` | 예정 |

### 7.3 SEO · 운영

- 구현됨: 정적 생성, title·description·canonical, sitemap·robots, 글마다 `BlogPosting` JSON-LD, OG 이미지, RSS(`/feed.xml`), GA(프로덕션만), Speed Insights
- 홈의 문구·메뉴는 HTML로 먼저 렌더링되어야 한다 (HUD여도 일반 링크)
- `.env*`는 커밋하지 않는다. 라이선스(제안): 코드 MIT, 글 CC BY-NC 4.0
- vault 연동: 보류

## 8. 기술

```text
apps/web                 Next.js 16 (App Router) + React 19 + TypeScript, CSS Modules
  app/page.tsx           홈 (지금은 창밖 우주만: components/space/)
  app/writing/           글 목록·상세, content/writing/*.mdx
art/                     기준 그림 (art/README.md)
```

- 배포: Vercel(`apps/web` 루트), `main` 푸시 시 프로덕션
- 창밖 영상: H.264(mp4) + VP9(webm), 2~4MB 목표. 포스터는 정지 그림
- v2.0 Godot 섬 월드의 설계·소스는 `main` 브랜치에 있다. 시안 a·b·c·d는 `proto/home-directions` 브랜치에 있다
