## 0. 작업 원칙

- **콘셉트는 방향이지 완성본이 아니다.** 콘셉트 그림과 시안 D(`proto/home-directions` 브랜치의 커밋 `2311481`, `apps/web/app/proto/d`)는 구도·화풍·동작의 견본이다. 컴포넌트를 만들 때마다 이 콘셉트를 바탕으로 디테일과 분위기를 **다시 설계해서** 구현한다. 시안 코드를 그대로 옮기지 않는다.
- 컴포넌트 하나를 만들 때마다 콘셉트 그림과 나란히 비교해 보고 결정한다.
- 콘셉트 그림은 아트 디렉션 기준이며 그대로 리소스로 쓰지 않는다.

## 2. 비전

**Deep Thought는 읽고, 탐험하고, 질문하고, 놀 수 있는 개인 지식 우주다.**

- **사이트 이름:** Deep Thought (『은하수를 여행하는 히치하이커를 위한 안내서』의 컴퓨터)
- **세계관:** *Zannabi's Little Universe*
- **마스코트:** **Zannabi(잔나비)**, 우주를 탐험하는 원숭이 ("잔나비"는 원숭이의 옛 우리말)
- **부브랜드:** Zannabi Lab
- **주제:** 소프트웨어 엔지니어링, AI/에이전트, 사이드 프로젝트, 독서·철학, 사고와 실험의 기록

### 핵심 원칙

1. 게임처럼 재미있지만 **블로그로서도 훌륭해야 한다.**
2. HUD 조작은 **보조 탐색 경로**다. 메뉴·검색·직접 URL로 모든 콘텐츠에 갈 수 있어야 한다.
3. 귀여운 마스코트와 전문적인 콘텐츠를 분리해 표현한다.
4. 첫인상보다 **읽기·접근성·성능·모바일**을 우선한다.
5. **사용자는 기다리지 않는다.** 화면은 즉시 보이고, 움직임은 준비되는 대로 더해진다.

## 3. 홈 콘셉트: 우주선 창

**작은 픽셀 아트 우주선의 큰 창 너머로 진짜 우주를 바라보는 콕핏. 왼쪽엔 로고, 오른쪽엔 블로그로 들어가는 패널, 아래엔 그 안에서 생활하는 Zannabi.**

기준 시안은 `art/refs/concept/home-gpt-v3.png`. 시안은 방향일 뿐이고 컴포넌트마다 다시 설계한다 (§0).

### 3.1 층

| 층 | 내용 | 화풍 | 만드는 법 |
| --- | --- | --- | --- |
| 창밖 | 행성 2개, 바위, 성운, 별 | **실사** | 4K 그림을 시작 프레임으로 Kling 3.0 Omni (Frames) 10초 → 4K 업스케일(Bytedance) → 정방향+역방향 이어 붙인 핑퐁 반복(`public/world/space-loop-4k.mp4`, 8.3MB, 데스크톱만). 포스터는 영상 첫 프레임 |
| 우주선 | 모서리를 깎은 큰 창틀, 창턱 바닥, 깜빡이는 표시등 6곳 | **픽셀 아트** (던전앤파이터 정도 밀도) | GPT 그림 → `window_frame.py`(2px 격자, 48색, 가짜 글자 제거, 불빛 분리) → `WindowFrame.tsx`가 정수배로 그리고 이음 열·행을 복제해 화면 비율에 맞춘다 |
| 로고 | "A LITTLE UNIVERSE OF IDEAS" / DEEP THOUGHT / "Still computing the answer." | **픽셀 아트** (크림·보라) | GPT 그림 → `logo.py`(420×202, 반짝이·토성 분리, 위아래 작은 문구는 지움) → `HomeLogo.tsx`가 배율대로 늘리고 위치를 기기 픽셀 경계에 맞춘다. 위아래 문구는 픽셀 글꼴 글자로 다시 쓴다(위 12px, 아래 24px) — 그림째 늘리면 획이 깨져 보였다 (2026-11-18) |

### 3.3 요소

| 요소 | 역할·콘텐츠 | 동작 |
| --- | --- | --- |
| **상단 메뉴** | Writing · Portfolio · Resume · Lab · Arcade | SVG 아이콘 + 탭 알약. 아직 없는 메뉴는 호버 시 스크램블로 `COMING SOON` |
| **Command palette** | 공개 글 검색, 프로젝트 검색, 페이지 바로가기 | 클릭 또는 `Ctrl K` / Mac `⌘ K`. 방향키로 고르고 Enter로 이동. 글이 쌓이기 전에는 바로가기 위주 |
| **메인 로고** | 사이트 정체성과 두 줄 슬로건 | 위에서 아래로 그려지는 등장, 반짝이 깜빡임, 토성 떠다님. 내부 페이지에서는 홈 링크 |
| **Mission Log** | 최신 공개 글 3개: 제목·카테고리·발행일 | 행 전체가 글 링크. '전체 글'은 Writing으로. 글이 없으면 빈 상태 |
| **Ask Zannabi** | 공개 글·프로젝트·이력에 관한 질문 | 질문 → 대화 패널, 답변과 원문 링크. 서버가 없어 우선 UI만 (`COMING SOON`) |
| **레트로 단말기** | Ask Zannabi의 시각적 상징 | 대기 중 커서 깜빡임, 답변 생성 중 화면 변화 |
| **Arcade 배너** | 대표 미니게임 또는 게임 목록 진입 | `Play`. 게임 전까지 `COMING SOON` |
| **Zannabi** | 콕핏에서 생활하는 마스코트 | 창밖 보기·걷기·책 읽기. 멈춰 있는 시간을 길게 |
| **카피라이트** | `© 2026 Deep Thought. All rights reserved.` | 오른쪽 아래에 작게 |

- **로고 크기:** 창 유리 폭의 약 28%. 420px 그림 도트를 기기 픽셀 기준 2배 미만은 0.25배 단위, 그 위는 정수배로 끊는다 (1080p 1.25배 525px). 1.5배(630px)는 사용자가 조금 크다고 했다. 배율마다 원본에서 윤곽을 다듬어 다시 찍는 안도 만들어 봤지만, 계단이 고른 대신 글자 가장자리의 보라색 디테일이 사라져서 사용자가 420px 그림을 늘려 쓰는 쪽을 골랐다. 315px 격자로 다시 뽑는 안은 작은 문구가 뭉개졌다 (2026-11-18)
- **배치:** `HomeHud`가 유리 영역을 `1fr | minmax(380px, 31%)` 두 칸으로 나눈다. 오른쪽은 패널, 위 96px은 메뉴 줄 자리 (패널은 Mission Log부터 하나씩 만든다)
- **색:** 로고의 크림 `#FAE8BC`·라벤더 `#9A7EB0`만. 패널은 어두운 반투명 바탕 + 라벤더 픽셀 테두리(창틀 도트 2개 굵기, 모서리 한 칸 깎음 — box-shadow 4방향으로 시험해 봄)
- **글꼴:** 영문 메뉴·위젯 제목·날짜는 **Fusion Pixel 12**(픽셀 고정폭, 12px 격자라 12·24px로 쓴다. 패널 제목 24px), 한글 제목·설명은 **Pretendard**. Departure Mono는 너무 투박했고, VGA 9×16 계열·Doto·Bitcount·Geist Pixel·Silkscreen·Pixelify Sans·VT323과도 비교했다 (2026-11-18)

### 3.4 움직임

- **움직이는 것은 사물만:** 창밖 우주(바위 회전·떠다님, 성운 일렁임, 큰 별 반짝임, 행성 대기 빛), 표시등, 로고 조각, Zannabi의 작은 동작. **카메라와 행성 위치는 고정**
- **전원 켜기 순서:** 어두운 창틀 → 표시등 지지직 → 실내 밝기 → 창밖 → UI·로고 (`SpaceScene.tsx`)
- 별똥별과 마우스 시차는 영상이 아니라 웹 코드로 얹는다 (영상에 넣으면 같은 자리에서 반복돼 티가 난다)
- 별똥별(`components/space/ShootingStars.tsx`): 7~19초에 한 번, 두 행성이 마주 보는 축(약 40.5°)을 따라 위 행성 쪽에서 아래 행성 쪽으로, 축 양옆 빈 통로에서만 떨어진다. 행성·바위 앞은 지나가지 않는다. 개발 서버에서 `?meteors`면 자주 나온다
- 창틀 배율: 원본 2배 크기를 기준으로 반올림 (1080p·창 모드 1배, 1440p·레티나·4K 2배)
- `prefers-reduced-motion`이면 영상 대신 정지 그림, 애니메이션 끔

### 3.5 모바일 (예정)

창틀 없이 우주와 UI를 세로로 쌓는다. 영상 대신 정지 그림.

| 1 | **Star Patrol** | 고정 화면 우주 슈팅 (시안 D에 160×144 견본) |
| 2 | **Moon Breaker** | 우주 테마 벽돌깨기 |

- 홈의 Arcade 배너에서 들어간다. 게임 화면은 게임보이 해상도(160×144)·4색으로 한다. 전용 페이지(`/arcade/[game]`)는 필요해지면 만든다.
- 점수는 처음엔 브라우저 로컬 저장.
- 고전 게임의 **장르와 추상적 메커니즘**만 참고한다. 원작 코드·그래픽·음악·캐릭터·상표·적 디자인을 따라 하지 않는다.

## 7. 콘텐츠 · SEO · 운영

### 7.1 콘텐츠

- 원본: `apps/web/content/{writing,projects,reading}/*.mdx`, 빌드 시 정적 생성. 지금은 `writing`만 있다.
- 프런트매터 스키마는 빌드 시 검증한다 (`lib/writing.ts`).
- 새 글은 `content/writing/_template.mdx`를 복사해 영문 소문자·하이픈 이름으로 저장한다. `draft: true`면 개발 서버에서만 보인다.
- 시설 콘텐츠 순서: Writing → Projects → Reading → Ask → Arcade. 오픈에는 Writing·Projects가 필수.

### 7.2 URL

| 경로 | 내용 |
| --- | --- |
| `/` | 홈 (만드는 중. 지금은 창밖 우주 배경만) |
| `/writing`, `/writing/[slug]` | 글 목록, 글 상세 (구현됨) |
| `/projects`, `/reading`, `/about` | 예정 |

### 7.3 SEO · 운영

- 구현됨: 정적 생성, title·description·canonical, sitemap·robots, 글마다 `BlogPosting` JSON-LD, OG 이미지, RSS(`/feed.xml`), GA(프로덕션만), Speed Insights
- 홈의 문구·메뉴는 HTML로 먼저 렌더링되어야 한다 (HUD여도 일반 링크)
- `.env*`는 커밋하지 않는다. 라이선스(제안): 코드 MIT, 글 CC BY-NC 4.0
- vault 연동: 보류

## 8. 기술

```text
apps/web                 Next.js 16 (App Router) + React 19 + TypeScript, CSS Modules
  app/page.tsx           홈 (지금은 창밖 우주만: components/space/)
  app/writing/           글 목록·상세, content/writing/*.mdx
art/                     기준 그림 (art/README.md)
```

- 배포: Vercel(`apps/web` 루트), `main` 푸시 시 프로덕션
- 창밖 영상: H.264(mp4) + VP9(webm), 2~4MB 목표. 포스터는 정지 그림
- v2.0 Godot 섬 월드의 설계·소스는 `main` 브랜치에 있다. 시안 a·b·c·d는 `proto/home-directions` 브랜치에 있다
